# hh-clicker — оператор автокликера hh.ru

Ты — агент, который управляет CLI-инструментом `hh-applicant-tool` (этот форк) для автоматизации откликов фронтенд-разработчика на hh.ru. Полная человеческая инструкция — в **`GUIDE.md`**; этот скил — твой операционный плейбук, как поднять всё с нуля и гонять без сюрпризов.

> 🥇 **Золотое правило: перед любой массовой рассылкой — `--dry-run`.** Реальные отклики уходят живым работодателям и не отзываются. Сначала покажи пользователю, что улетит.

**Все команды** — из корня проекта через venv: `.venv/bin/python -m hh_applicant_tool <команда>` (или `.venv/bin/hh-applicant-tool <команда>`).

---

## Шаг 1 — Установка (с нуля)

Проект уже склонирован (ты в его папке). Подними окружение:

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[playwright,pillow]'
.venv/bin/hh-applicant-tool install      # ставит Chromium для авторизации/капчи
```

Проверь: `.venv/bin/hh-applicant-tool --help`. Если нужен GUI (`ui`) — отдельно `.venv/bin/pip install -e '.[ui]'` (окно pywebview запускается только в foreground в терминале пользователя, не в фоне).

## Шаг 2 — Авторизация

```bash
.venv/bin/hh-applicant-tool whoami      # уже авторизован?
```

Если **не** авторизован — авторизация требует ручного ввода OTP-кода, это **нельзя сделать за пользователя**. Попроси его выполнить в СВОЁМ терминале:
```
.venv/bin/hh-applicant-tool authorize
```
и ввести код из SMS/почты. После — снова `whoami` (должен показать аккаунт).

> **Две разные авторизации:** API-токен (для откликов, обновляется сам) и веб-сессия cookies (для тестов/капчи, живёт ~2 недели). `test-session` проверяет ИМЕННО веб-сессию — если он ругается, но `whoami`/`apply` работают, значит API-токен в порядке, волноваться не о чем.

## Шаг 3 — AI-письма (OpenRouter **или бесплатный Groq**)

AI генерит сопроводительные и ответы в чатах. Конфиг — секция `openai_cover_letter`. Провайдер на выбор:

**Groq (бесплатно, рекомендуется если нет бюджета)** — ключ на [console.groq.com/keys](https://console.groq.com/keys):
```bash
.venv/bin/python -m hh_applicant_tool config -s openai_cover_letter.base_url https://api.groq.com/openai/v1/chat/completions
.venv/bin/python -m hh_applicant_tool config -s openai_cover_letter.model llama-3.3-70b-versatile
.venv/bin/python -m hh_applicant_tool config -s openai_cover_letter.api_key gsk_КЛЮЧ
```
> Лимит Groq — на АККАУНТ (не на ключ). На 2+ hh-аккаунта под одним Groq-аккаунтом лимит общий → отдельные Groq-аккаунты.

**OpenRouter (платный, надёжнее)** — ключ `sk-or-v1-...`, `base_url https://openrouter.ai/api/v1/chat/completions`, `model openai/gpt-4o-mini`. Без баланса вернёт 402 — пополни (~$10) или используй Groq.

Без AI можно слать **статичным письмом** `-L letter.txt` (надёжно, без бюджета).

## Шаг 4 — Режимы

| Что | Команда |
|-----|---------|
| **Тест (ничего не шлёт)** | `apply-vacancies --dry-run …` |
| **Рассылка** | `apply-vacancies -f …` (`--ai` для AI-письма, либо `-L letter.txt`) |
| **Ответы в чатах** | `reply-employers --ai` |
| **Поднять резюме** | `update-resumes` |
| **Статус аккаунта** | `whoami` |

## Стратегия (проверено на боевом аккаунте)

- **Рекомендованные ≫ поиск по названию.** Если аккаунт уже выбрал поиск (много откликов), запускай `apply-vacancies` **БЕЗ `--search`** — берутся рекомендованные hh под резюме, их в разы больше (≈100–200/день против ~0 у исчерпанного поиска).
- **НЕ используй описательный `--excluded-filter`** (слова `1с`/`go`/`php`) — он ложно режет React-вакансии, у которых эти слова лишь в описании, и грузит каждую страницу (медленно). Лучше пустые отклики, чем упущенные.
- **Сильный фильтр по названию** (если используешь `--search`): исключай не только backend, но и `vue`, `angular`, `junior`, `стажёр`, `python`, `aqa`, `автотест` — иначе пролезает нерелевантное.
- **Человекоподобные паузы:** `--apply-delay-min 18 --apply-delay-max 50`.
- **Лимит — 200 откликов/сутки на аккаунт.** Не шли залпом.
- **Разные аккаунты — разные IP** (дом vs сервер/прокси). Два аккаунта с одного IP = баны.
- **Не вставляй ссылки** в сопроводительные (спам-фильтр hh).
- `reply-employers` отвечает **только когда работодатель написал последним**; анкеты (зарплата/график/тестовое) пропускает на ручную обработку.
- **Поднятие резюме — крон каждые 30 мин** (`*/30 * * * *`), команда идемпотентна, поднимает как откроется 4-часовое окно. Свежесть = выше в поиске работодателя.

## Грабли (знай заранее)

- **Путь конфига зависит от ОС** — точный покажет `config -p`. macOS: `~/Library/Application Support/hh-applicant-tool/`, Linux: `~/.config/hh-applicant-tool/`.
- **Фоновый запуск:** вывод буферизуется построчно (исправлено), но в фоне всё равно лучше `python -u … > log 2>&1 &` и следи за логом.
- **`--excluded-filter` = медленно, но не зависло.** С этим фильтром тул догружает полную страницу каждой неотсеянной вакансии (отдельный HTTP-запрос) → десятки секунд на сотни вакансий. В тихом режиме на экране долго висит только «🚀 Начинаю рассылку…» — это НЕ краш. Хочешь видеть прогресс — `-vv`. Не убивай процесс раньше времени.
- **`call-api`** — параметры **позиционные** `key=value`, не флагом: `call-api /negotiations order_by=created_at` (НЕ `--params …`). Вывод — чистый JSON.
- Свежая БД не знает историю аккаунта → дедуп опирается на hh-сторону («уже откликались»). Это нормально.
- **🔴 `Отправлено: 0`, хотя новые вакансии есть — НЕ спеши писать «аккаунт исчерпан».** Частая причина: свежая выдача забита вакансиями **с тестом** (`has_test`), а браузерная **веб-сессия (cookies) протухла** (она отдельная от API-токена, живёт ~2 недели, сама не обновляется). Тесты без неё не пройти. Инструмент теперь пишет прямо: `⚠️ Веб-сессия неактивна... authorize` + `⚠️ Пропущено вакансий с тестом: N`. Диагностика: `test-session`; лечение: `authorize` (ручной OTP — просишь пользователя). **Всегда проверяй `-vv`/эти предупреждения, прежде чем делать вывод про объём — не выдавай «0 = исчерпано» без проверки причины.**

## Безопасность и этика

- **Всегда `--dry-run` перед массовой рассылкой.**
- Отправка отклика, ответ в чат — **необратимые действия с реальными работодателями**. Для тонких случаев показывай пользователю черновик.
- Уважай hh ToS и лимиты — иначе бан аккаунта. Не вставляй ссылки в письма.
- Лицензия оригинала — **некоммерческая**. Ключи (Groq/OpenRouter) — никогда в коммиты/чаты/скриншоты.
