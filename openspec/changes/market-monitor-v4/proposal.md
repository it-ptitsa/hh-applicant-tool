# Мониторинг рынка v4: без детальных карточек, полная выдача, проверки перед отправкой

## Why

06.10.2026 Александр: «хочу быть уверенным на 100%, что ты не ошибаешься при формировании
отчёта». Полный просмотр живых данных вскрыл три системные проблемы:

1. **Выдача собиралась не полностью.** При сортировке по релевантности (по умолчанию) страницы
   hh перекрываются: из 888 найденных собиралась 731 уникальная (−18% рынка во всех отчётах до v4).
   По дате публикации — 888 из 888.
2. **Детальные карточки ловят капчу на аккаунт** (05–06.10 — на обоих аккаунтах), без них v3 не
   различал новые и переоткрытые. Номера вакансий hh монотонны по дате создания (0 нарушений на 166
   карточках); опорные точки «номер → время» из поиска дают возраст без карточек — бэктест на 166
   карточках: новые 97/97, поднятые 48/48, ошибок 0.
3. **Классификатор ошибался на ~10% фронта**, хотя 370 тестов были зелёными: живая выдача
   богаче придуманных случаев.

## What Changes

- Пагинация только с `order_by=publication_time`.
- Возраст по номеру вакансии и опорным точкам (поиск за 12:00–13:00 МСК каждого из 31 прошлого
  дня + «сейчас» + даты из старых карточек); детальные карточки не запрашиваются.
- Закрытой считается вакансия, которой нет в выдаче 3 дня подряд (30.09–05.10: пропавшие на 1–2 дня
  вернулись в 47 случаях, на 3+ — ни одна из 53).
- Дельты считаются пересчётом прошлого снимка текущим классификатором — сравнимы при правках.
- React Native — во фронте отдельной строкой стека (решение Александра 06.10).
- Кириллические двойники латиницы в названиях («аngular», «Middlе», «С#») и десктоп-«фронтенд»
  (Qt, WPF, Avalonia) классифицируются верно.
- Ежедневный отчёт по согласованному макету; недельный отчёт по понедельникам.
- Проверки перед отправкой: полнота выдачи, суммы, скачки > 15%, неизвестный возраст → в шапке
  «Не пересылать».
- Эталон 748 просмотренных названий (тест требует 100% совпадения) и очередь новых названий на
  независимую проверку агентом; решения по спорным применяются к отчётам.
- Срез JS-рынка из v3 заменён ежедневным отчётом.
